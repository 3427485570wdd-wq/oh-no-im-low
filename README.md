# Oh No, I’m Low! · V0.1

低血糖互动游戏的第一个网页版本。本版保留真实的阶段边界，先完成桌面显示与图层结构。

## 打开方式

直接用浏览器打开 `index.html` 即可，无需安装依赖。

如果电脑已安装 Node.js，也可以在此文件夹的终端运行：

```sh
npm run dev
```

然后打开终端显示的本地地址。按 Ctrl+C 关闭预览服务。

## 本版已完成

- 已确认的粉紫色桌面背景与六款食品 SVG。
- 七个独立食品对象；两包草莓软糖共用一份素材。
- 桌面、食品层与固定主界面分离。
- 自动按可用窗口尺寸完整适配画面，保持原始比例。
- 主界面保留张嘴／闭嘴分组，默认闭嘴。
- 素材全部保存在本地，不通过网络请求字体或图片。

## 本版边界

这是桌面初始展示版本。鼠标拖拽、点击按钮、进食、摄像头、缩放平移、
等待、补充记录和结局逻辑尚未接入。状态条长度是视觉示例。
页面不会请求摄像头权限，也不会采集身体数据。

## 文件结构

- `index.html`：页面入口与三个场景层。
- `styles.css`：整体布局、食品位置和屏幕适配样式。
- `src/scene-data.js`：七件食品的身份、素材与位置。
- `src/app.js`：生成独立食品、加载状态和窗口适配。
- `assets/`：桌面背景、食品 SVG、固定主界面 SVG。
- `tools/serve.cjs`：使用 Node.js 自带功能的可选本地预览服务。
- `CHANGELOG.md`：每版的新增内容与保留问题。

食品 SVG 已收紧画布范围，以匹配桌面摆放预览；图形仍保留可编辑路径。
原始全景、完整画布素材和概念稿仍保存在此前项目目录中。
