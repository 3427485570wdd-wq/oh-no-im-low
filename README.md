# Oh No, I’m Low! · V0.3

V0.3 在已完成的桌面循环上接入摄像头手势抓取，保留鼠标与键盘操作。旧版保留在 Git 历史与版本标签中。

## 打开和运行

无需安装依赖。摄像头模式需使用HTTPS网址，或本机HTTP预览（localhost／127.0.0.1）。直接双击 `index.html` 时仅建议使用鼠标模式。安装 Node.js 后可在此目录运行：

```sh
npm run dev
```

打开终端显示的本地地址，按 Ctrl+C 停止服务。建议使用桌面浏览器或横屏。

## 怎么玩

1. 选择“开启摄像头”，在浏览器中允许访问。画面不显示真人，模型文件从本项目加载；把一只手放到镜头前，先松开拇指和食指。
2. 显示已识别、开始按钮可用后，点击“开始寻找”，开局倒计时为01:00。
3. 移动食指控制粉色光标；对准食品后用拇指与食指捏合拿起，继续移动，松开放下。
4. 持有食品进入下方进食区时按住空格张嘴，或先点击嘴巴切换开合；一次吃下整份。真实张嘴识别留到下一版。
5. 钟表等待结束后，根据状态继续寻找或进入结果；食品记录与碳水合计沿用现有规则。

“使用鼠标开始”可直接进入原鼠标玩法。顶栏的“开启手势／手势设置”可切换输入方式；“改用鼠标”会关闭摄像头、终止模型Worker并释放视频流。拒绝权限、没有摄像头或模型加载失败时仍可使用鼠标。

识别暂时丢失会立即停住寻找、等待与状态变化，取消当前抓取并退回抓起前位置；提示页出现后，重新识别到手、松开捏合，再点击继续。追踪错误不触发失败。阅读记录、手动暂停和后台切换也会停表。重新开始会恢复七件食品并清空本局记录。

手势抓取时按住空格；同一时间只需识别一只手。若光标跳动，先改善光线、让整只手留在镜头内。界面提供鼠标回退，无需反复授权。

鼠标模式：按住左键拖动食品，松开放下。键盘辅助：Tab 选择，Enter 拿起／放下，方向键移动，Shift+方向键加快，空格张嘴，Esc 取消拿取或暂停。

## 本版预设与边界

食品整份操作，一件只能吃一次。F06、F07 两包软糖分别计数。F01 硬糖袋16.5g碳水、F02 心形盒软糖7.7g、F03 果汁15g、F04 饼干7.3g、F05 无糖汽水0g、F06／F07 每包15.3g。记录显示总碳水，不等同于包装中的“糖”一项。

等待实际4秒，渐暗2秒。主界面只用无刻度状态条，等待只显示钟表，不显示血糖读数、百分比或公式。饼干部分响应推迟到下一次等待，无糖汽水不增加碳水；模拟中的背景下降仍会继续。

内部参数集中在 `game-rules.js`；沿用已同意暂用于本版的草案：初始3.4、恢复4.0、危险3.0、失败2.5；开局寻找预算60秒，下降节奏按初始状态到失败线均匀分配，等待背景下降0.1，响应系数0.06，饼干40%本轮、60%下轮。这些只是可调游戏参数，不是医学换算、诊疗目标或晕倒阈值；正式公开传播前仍需专业审校。食品份量和碳水为预设参考值，不代表图片中的包装具有真实标签。

失败说明参考 [ADA 低血糖说明](https://diabetes.org/living-with-diabetes/hypoglycemia-low-blood-glucose)。游戏结果不能用于判断真实血糖或决定现实中的补糖量。

本版已加入摄像头手部识别，尚未加入真实张嘴、脸部缩放平移、音效或非食品抓取。模型推理在独立Worker里进行，最多约15帧／秒且同一时刻只处理一帧。摄像头仅在主动选择手势模式后申请，原始画面不显示、不保存、不上传；本局记录仅保存在内存，刷新即清空。关闭摄像头、切回鼠标或离开页面会释放视频流。

识别基于 [Google官方Hand Landmarker接口](https://developers.google.com/edge/mediapipe/solutions/vision/hand_landmarker/web_js)。运行库固定为 `@mediapipe/tasks-vision 1.1.1`，模型在2026-10-27下载并以本地文件和SHA-256锁定，运行时不依赖外部CDN。许可证与来源见 `assets/vendor/mediapipe/NOTICE.md`。每个模型／运行文件均小于25 MiB，保留现有Cloudflare排除规则。

## 当前验证状态

13项原有玩法与资源检查、9项手势和摄像头检查通过。已在Chrome中以官方公开手部样例实际运行本地Worker与模型，输出一只手及21个关键点；不是模拟识别结果。参与者已实测真实摄像头识别、食指移动、捏合拿起与松开放下；已观察到识别丢失时停表和提示恢复。另在当前项目复核了鼠标回退、空格进食、7.7g记录、钟表等待及恢复分支。

食品位于嘴边但未张嘴时，现显示“按住空格张嘴”；直接松手未吃下时会明确反馈，不计入摄入。真实张嘴识别留到下一版，当前仍需按空格或点击嘴巴。

本轮浏览器控制台未见警告或错误。实际截图位于 `docs/versions/v0.3-camera.png` 与 `v0.3-mouth-prompt.png`。尚未进行多设备和长时间连续手势实测，手感参数可在 `hand-gesture.js` 中继续微调。
