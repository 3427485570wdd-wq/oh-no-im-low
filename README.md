# Oh No, I’m Low! · V0.2

V0.2 合并原计划中的第二、第三版本：在同一张桌面上完成鼠标寻找、进食、等待、查看记录和结果循环。V0.1 保留在 Git 历史与 `v0.1.0` 标签中。

## 打开和运行

无需安装依赖。用浏览器打开 `index.html`，或安装 Node.js 后在此目录运行：

```sh
npm run dev
```

打开终端显示的本地地址，按 Ctrl+C 停止服务。建议使用桌面浏览器或横屏。

## 怎么玩

1. 点击“开始寻找”，顶部出现寻找倒计时，开局为01:00。剩余时间按当前模拟状态计算，进食结算后可能延长；暂停、查看记录和进食后的等待阶段停表，归零时沿用渐暗结束。它是游戏时间，不是现实低血糖的安全时间。
2. 按住鼠标左键拿起食品，拖到下方进食区；松开可放在桌面其他位置。
3. 按住空格键张嘴，持有的食品中心进入进食区后，自动吃下整份。也可先点击嘴巴保持张开，再拖动食品。
4. 等待钟表完成。状态改善但未恢复时继续在同一桌面寻找，恢复后进入回顾；持续恶化会渐暗并结束本局。
5. “补充记录”显示本局食品、份量、各项碳水和合计。查看时寻找、等待和渐暗均暂停；关闭后继续。

右上角可暂停、重新开始。Esc 可暂停或返回。切换窗口、切到后台时自动暂停，需要点击继续。重新开始会恢复七件食品并清空本局记录。

键盘辅助：Tab 选择食品，Enter 拿起／放下，方向键移动，Shift+方向键加快，空格张嘴，Esc 取消拿取。触屏可先点嘴巴，再拖动食品。

## 代码在哪里

| 文件 | 职责 |
|---|---|
| `index.html` | 场景层、内嵌可编辑固定 SVG、钟表和弹层容器 |
| `styles.css` | 布局、交互反馈、等待及弹层外观 |
| `src/scene-data.js` | 七件食品的位置、身份、份量和碳水 |
| `src/game-rules.js` | 独立模拟规则、状态分支、等待、延迟响应、记录合计 |
| `src/app.js` | 鼠标／键盘、嘴巴同步、面板、暂停、动画与规则连接 |
| `assets/` | 已确认的桌面和食品；原主界面 SVG 保留为参考源 |
| `tools/test-game.cjs` | 进食、延迟响应、记录、暂停和失败分支场景检查 |
| `docs/versions/` | 各版实际网页截图 |

固定主界面现内嵌于 HTML，便于直接修改状态条和两种嘴巴分组；原 `assets/ui/main-game-ui.svg` 不再直接作为网页图片显示。

## 本版预设与边界

食品整份操作，一件只能吃一次。F06、F07 两包软糖分别计数。F01 硬糖袋16.5g碳水、F02 心形盒软糖7.7g、F03 果汁15g、F04 饼干7.3g、F05 无糖汽水0g、F06／F07 每包15.3g。记录显示总碳水，不等同于包装中的“糖”一项。

等待实际4秒，渐暗2秒。主界面只用无刻度状态条，等待只显示钟表，不显示血糖读数、百分比或公式。饼干部分响应推迟到下一次等待，无糖汽水不增加碳水；模拟中的背景下降仍会继续。

内部参数集中在 `game-rules.js`；沿用已同意暂用于本版的草案：初始3.4、恢复4.0、危险3.0、失败2.5；开局寻找预算60秒，下降节奏按初始状态到失败线均匀分配，等待背景下降0.1，响应系数0.06，饼干40%本轮、60%下轮。这些只是可调游戏参数，不是医学换算、诊疗目标或晕倒阈值；正式公开传播前仍需专业审校。食品份量和碳水为预设参考值，不代表图片中的包装具有真实标签。

失败说明参考 [ADA 低血糖说明](https://diabetes.org/living-with-diabetes/hypoglycemia-low-blood-glucose)。游戏结果不能用于判断真实血糖或决定现实中的补糖量。

本版没有摄像头、脸部缩放平移、手势模型、音效或非食品抓取。仅使用本地内存保存本局记录，刷新即清空，不申请摄像头权限。
